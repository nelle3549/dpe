The big idea

A workbook is a binder. Each worksheet is a tabbed divider.

  • Workbook = the whole file, like one binder on the shelf.
  • Worksheet = one page section inside, with its own tab at the bottom of the screen.
  • Coloured, clearly labelled tabs help anyone find January in a second.
  • The Summary divider in front gives the boss the totals first.

Everyone in a government office knows binders with dividers. A workbook is the binder; each worksheet is a section with its own tab.

Ask: "Would you file January's and February's documents in the same section with no divider?" No. Same in a spreadsheet: one month per sheet keeps each table clean, and identical layouts make the Summary formulas easy.

Choose the right action

Hide, delete or protect: they are not the same

Hide

Takes a sheet out of view, for example a helper sheet of price lists. Anyone can unhide it in two clicks.

Delete

Removes the sheet and everything on it. Formulas that pointed to it show #REF!.

Protect

Lets people see the sheet but stops them from changing locked cells, like your formulas.

Hiding is not security. Never "hide" taxpayer details or other confidential data in a shared file. If people shouldn't see it, it shouldn't be in that file.

A frequent misunderstanding: people hide a sheet and think the data is safe. It isn't. Right-click any tab, Unhide, and it's back.

For our office, this matters under the Data Privacy Act: personal information must be protected properly, not tucked away out of sight. If a file goes to other sections, remove what they don't need. Deleting is also risky; any Summary formula pointing to the deleted sheet turns into #REF!.

Referencing other sheets

Sheet name, then !, then the cell.

  • =Jan!E10 means "cell E10 on the Jan sheet".
  • Easiest way: type =, click the Jan tab, click E10, press Enter.
  • Names with spaces need quotes: ='Jan 2026'!E10.
  • LibreOffice writes it as =$Jan.E10. Clicking writes it for you.

This is the payoff of identical month sheets: every month's grand total sits in E10, so the Summary is three short formulas plus a SUM.

Jan is our real dataset, ₱22,039.00. Feb and Mar use sample quantities: ₱17,518.00 and ₱24,652.00. The quarter is ₱64,209.00, average ₱21,403.00 a month. Demo the click method; don't make them type exclamation marks. If someone fixes a number on the Feb sheet, the Summary updates on its own.

See it everywhere

One tab per period, one Summary in front

At the office
  • Supplies inventory: Jan, Feb, Mar tabs; a Summary for the quarterly report.
  • Attendance: one tab per month, a Summary that counts days present per person.
  • Incoming documents log: one tab per week, frozen headers, filter by section.
At home
  • Household budget: a tab per month (rice, CEPALCO bill, water, load), and a Year tab.
  • Sari-sari sales: a tab per week, Summary shows the best week.

The same structure works for almost any record that repeats by period. The trick is identical layouts: make January perfect, then copy the sheet.

Ask the chat: "Which file in your section would be easier with one tab per month?" Attendance and supplies come up often. For home, a budget workbook with a Year tab shows exactly when the electricity bill peaked in summer.

Find it in seconds

Find and Replace

Ctrl + FFind a word or number anywhere on the sheet, like "Envelope". Ctrl + HReplace one spelling with another, for example "Ballpen" with "Ball pen".

Same keys in Excel, Google Sheets and LibreOffice Calc. Mac Excel: Cmd + F.

Careful with Replace All. Replacing "long" with "legal" changes all three items that contain it: bond paper, folder and envelope. Use Find first, or tick Match entire cell contents.

Find saves you from scrolling a 500-row register to find one name. Replace fixes a spelling everywhere in one go.

Demo Replace All going wrong: replace "long" with "legal" and the bond paper, folder and envelope rows all change, not just the one you meant. Then undo with Ctrl + Z. The habit: Find first, look at what matches, then Replace. In Excel, click Options to see "Match entire cell contents" and "Within: Workbook".

Sort · Data > Sort

Largest Total Cost first

  1. Click one cell inside the table (not the whole column).
  2. Excel / Calc: Data > Sort. Sheets: Data > Sort range > Advanced, tick "Data has header row".
  3. Sort by Total Cost, largest to smallest.
Never sort one column alone. The rows get mixed up: ink could end up with the price of paper.

Sorting answers "what costs us the most?" Long bond paper is first at 7,950.00, then A4 at 6,125.00; staple wire is last at 384.00.

The big danger: selecting only column E and sorting it. Excel warns you with "Expand the selection"; always choose expand. Also leave the TOTAL row out: keep a blank row above it, or select A1:E9 only, or it gets sorted into the list.

Filter · show only what you need

Show only items over ₱300 each

  • Excel: Data > Filter (Ctrl + Shift + L). Sheets: Data > Create a filter. Calc: Data > AutoFilter.
  • Click the arrow on Unit Cost > Number Filters > Greater Than > 300.
  • In Excel, blue row numbers tell you a filter is on. Clear it when done.
Watch out: =SUM still adds hidden rows. E10 stays 22,039.00; the 3 visible rows total 6,110.00.

Filtering hides rows that don't match; it never deletes them. Three items cost more than ₱300 per unit: folders, printer ink and envelopes.

Point out the row numbers jump from 1 to 5 to 8: that's how you spot an active filter. The gold box is a common trap: the SUM in E10 still shows the full 22,039.00. If you need only the visible total, the SUBTOTAL function can do that; we won't need it for Lab 3. In Google Sheets, the condition is "Filter by condition, Greater than".

Sheet protection · basics

Let others type inputs, but not break your formulas

  1. Unlock the input cells (for example Qty, C2:C9): Format Cells > Protection > untick Locked. Every cell is locked by default.
  2. Turn on protection. Excel: Review > Protect Sheet. Sheets: Data > Protect sheets and ranges. Calc: Tools > Protect Sheet.
  3. Add a password only if your section can keep it safe, and record who has it.
Result: co-workers can update quantities, but the Total Cost formulas and the SUM stay safe from accidental typing.
Protection is not encryption. It prevents accidental edits. To keep a file private, store it in the right shared folder with the right access, or use a file password approved by your ICT focal person.

Protection is for accidents: someone types a number over your formula in E5 and the total quietly goes wrong. Unlock only the cells people should edit, then protect.

Demo in Excel: select C2:C9, Ctrl + 1, Protection tab, untick Locked; then Review, Protect Sheet. Try typing in E3: blocked. In Google Sheets, protection works by sharing permissions: you choose who may edit a range. Remind them: a forgotten sheet password is very hard to recover.

Preparing to print

One page wide, headers on every page

  1. Preview first: Ctrl + P. Count the pages.
  2. Fit to one page wide. Excel: Scaling > Fit All Columns on One Page. Sheets: Scale > Fit to width. Calc: Format > Page Style > Sheet > Scale.
  3. Print titles (repeat row 1). Excel: Page Layout > Print Titles > Rows to repeat at top $1:$1. Calc: Format > Print Ranges > Edit. Sheets: freeze row 1, then repeat frozen rows in the print settings.
  4. Landscape for wide tables; add the sheet name and page number in the footer.

The classic office complaint: a report prints on six pages, with the last column alone on page 2. Two settings fix most of it: fit all columns on one page and repeat the header row.

Demo Print Preview with Ctrl + P before and after. Notice $1:$1 in Print Titles: the absolute reference idea from 3.5 again. Save paper and toner: preview first, print once.
