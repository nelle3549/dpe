The big idea

A word processor is a typewriter that lets you change your mind.

  • Typewriter: one typo near the end and you retype the whole page, or reach for the correction fluid.
  • Word processor: fix one letter, move a paragraph, change the font, and the rest of the page adjusts by itself.
  • And it remembers: save the file once and you can reuse it next year with a new date.

Step 2 · Know the screen

Eight parts of the Word window

Microsoft Word

Microsoft Word for Mac. On Windows a File tab sits left of Home; on a Mac, File is in the menu bar at the top of the screen.

  1. Title bar: the file's name and where it is saved. AutoSave works for files in OneDrive or SharePoint.
  2. Quick Access Toolbar: Save, Undo, Redo, always in reach.
  3. Ribbon: tabs of command groups. File holds New, Open, Save As, Print, Export.
  4. Ruler: margins, indents and tabs. Turn on in View › Ruler.
  5. Document area: the page. The blinking line is the cursor, where text appears.
  6. Status bar: page number, word count, language.
  7. Views: Print Layout, Web Layout and more. Windows adds Read Mode.
  8. Zoom: bigger on screen only. Printing is not affected.

Vendor-agnostic

Where the same parts live in Docs and Writer

Google Docs in a web browser. Sample letter only.

  1. Commands: a menu bar and a toolbar instead of a ribbon.
  2. File menu: New, Open, Make a copy, Download, Print.
  3. Ruler: View › Show ruler.
  4. Word count: Tools › Word count (Ctrl+Shift+C).
  5. Zoom: the zoom box on the toolbar.
  6. Saving: automatic. The cloud icon means "Saved to Drive"; the clock opens version history.
Writer: menus and toolbars, View › Rulers, word count and zoom in the status bar, like Word.
Lost a button? Search: Word's Search box, Docs' Help › Search the menus (Alt+/).

Step 3 · File handling

Four commands you'll use every day

File tab / File menu

New

Start a blank document.

Ctrl+N

Open

Bring back a saved file.

Ctrl+O

Save

Update the same file, same name, same place.

Ctrl+S

Save As

Make a new copy: new name, folder or format.

F12 in Word · Ctrl+Shift+S in Writer

Think photocopier: Save writes on the original. Save As runs a photocopy and gives the copy a new label, leaving the original as it was.
Google Docs: no Save button. Use File › Make a copy instead of Save As, and File › Download for a file on your PC.

Which file format, and when?

The letters after the dot
FormatWhat it isBest for
.docxWord's standard format. Google Docs and LibreOffice open it too.Editing and sharing drafts
.docThe old Word 97 to 2003 format. Re-save as .docx when you can.Opening old files only
.odtOpenDocument Text, LibreOffice's standard. Word and Docs open it too.Editing in LibreOffice
.pdfA fixed "print" copy. Looks the same on any phone or PC.Final copies to send or print
Google DocsLives in Google Drive, not on your PC. Download as .docx or .pdf.Editing together online
.txtPlain text only: no fonts, bold or tables.Raw text, like our letter today
Rule of thumb: edit in .docx (or .odt), send the final in .pdf, and keep both.

Where does the file live?

Local or cloud, and what AutoSave does

Local

This PC, a shared network drive or a flash drive. Works offline, but if the drive dies, so does the file.

Cloud

OneDrive, SharePoint or Google Drive. Saves as you type, keeps version history, opens on any device.

  • Word: the AutoSave switch works only for files saved in OneDrive or SharePoint.
  • Docs: always saving. Watch for "Saved to Drive".
  • Writer: no AutoSave; it keeps recovery copies every 10 minutes by default.

Good habits

Name it so anyone can find it in 10 seconds

Type · Subject · Date
At the office

Letter - Digital Skills Workshop Invitation - 2026-11-03.docx

Report - Monthly Collection Summary - 2026-10.pdf

Folder: Shared drive › Admin › 2026 › Letters

At home

Budget - Household - 2026-11.xlsx

Enrollment Form - Juan Jr - SY 2026-2027.pdf

Folder: Documents › Family › School

  • Dates as YYYY-MM-DD so files sort in order
  • Versions as _v1, _v2, never "final final"
  • Avoid Document1, new letter (2), FINAL na talaga.docx
  • Windows refuses \ / : * ? " < > | in names

Sharing the final copy

Turn any document into a PDF

Microsoft Word for Mac, then Google Docs. Sample letter only.

  1. Word: File › Save As › Browse, set Save as type to PDF (*.pdf), click Save.Mac (shown): File › Save As…, set File Format to PDF.
  2. Google Docs: File › Download › PDF Document (.pdf). It lands in Downloads.
  3. LibreOffice: File › Export as › Export as PDF…, Export, then Save.
Keep the original. The PDF is for reading and printing. Future edits happen in the .docx.
Any other app on Windows: Print, then choose the printer Microsoft Print to PDF.

The brownout survival guide

The power went out. Is my letter gone?

Don't panic

Google Docs version history. The account name is hidden.

  • Word: reopen it. A Document Recovery pane lists rescued files. Never saved? On Windows: File › Info › Manage Document › Recover Unsaved Documents.
  • Google Docs: already saved. For an older state, click the clock (or File › Version history › See version history), pick a version, then Restore this version.
  • LibreOffice: reopen Writer. The Document Recovery window appears. Click Start.
Recovery is a safety net, not a plan. Word and Writer save recovery copies about every 10 minutes, so you can still lose 10 minutes of work. Press Ctrl+S after every paragraph.
