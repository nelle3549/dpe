The big idea

Mail merge works like party loot bags.

  • One design for every bag: that's your letter.
  • One list of the kids who are coming: that's your data source.
  • A blank name tag on each bag: that's the merge field. Each bag gets a different name.
Result: one letter + one list = many personalised letters, in one file.

How it works

Three parts make one merge

📄

1 · Main document

The letter that stays the same for everyone: the workshop date, venue, body, signature.

+
📊

2 · Data source

A separate list, usually a spreadsheet. One row per person, one column per detail.

+
🏷️

3 · Merge fields

Placeholders in the letter, like «Name», linked to the list's column headers.

=
✉️

Merged letters

One new file with a finished letter for each row: Juan's, Maria's, Pedro's…

Key idea: the data stays in the list. Fix a name in the list once, merge again, and every letter is corrected.

Step 1 · The main document

Write it once. Leave "name tags" where details change.

  • Everything in plain text is the same for everyone.
  • Each «field» is filled in from the list, one row per letter.
  • A field can be used more than once, like «Section» here.

Microsoft Word · Mailings tab

Insert fields, preview, finish

Steps 4 to 6
4🏷️

Insert Merge Field

Click where the name goes, then Insert Merge Field › Name. Repeat for Position and Section. Add spaces and punctuation yourself.

5👁️

Preview Results

Click Preview Results and use the arrows ◀ ▶ to see each person's letter. Click it again to see the fields.

6✅

Finish & Merge

Edit Individual Documents › All › OK. Word opens a new file (e.g. Letters1) with one letter per person. Save it.

Save both files: the main document (with fields) and the merged file (with names). The merged file is the one you submit for Lab 2.

Hands-on · in your own apps

Merge your invitation to 3 people

Try it nowSubmit in the portal when your merged file opens
  1. In a spreadsheet, type Name, Position, Section, Email in row 1, then 3 sample people in rows 2 to 4. Save as Workshop Invitees and close it.
  2. Open your invitation letter from Topic 2.3.
  3. Mailings › Start Mail Merge › Letters, then Select Recipients › Use an Existing List.
  1. Replace the typed name with Insert Merge Field › Name. Add Position and Section.
  2. Preview Results and click through all 3.
  3. Finish & Merge › Edit Individual Documents › All. Save the new file as Merged Invitations.

Free and open source

Google Docs

Built in only on some paid Google Workspace editions. On free accounts, you need a mail merge add-on with a Google Sheet.

Check your edition first
Before installing any add-on: ask your ICT focal person. An add-on can read the sheet you connect, so never use one with personal or taxpayer data.

Before you print or send

Preview, then check like a proofreader

  1. Look at the first, last and one middle letter, not just the first.
  2. Check spaces and punctuation around every field: "Dear Ana Reyes:" not "DearAna Reyes :".
  3. Check the record count: 3 people in the list should mean 3 letters.
  4. Use Edit Recipient List to untick anyone who should not get a letter.
  5. Print one test page before printing the whole batch.

Troubleshooting

Four common mail merge errors

What you seeLikely causeFix
Wrong names, or no names at allYou picked the wrong sheet or table in Select Table.Select Recipients again and choose the sheet that holds the list.
Blank letters at the endEmpty rows, or rows with only a space, in the list.Delete empty rows in the sheet, or untick them in Edit Recipient List.
Numbers lose their formatWord takes the raw value: 1500 instead of ₱1,500.00.Type the amount as text in the sheet, or fix the format in Word before merging.
Dates look differentA date like 19 November 2026 may show as 11/19/2026.Type the date as text in the sheet, or keep the date in the main letter instead.
