The big idea

Page setup is the frame around your words.

  • Paper size is the size of the frame: A4, Letter or long bond.
  • Margins are the white border inside it.
  • Orientation is whether you hang it tall (portrait) or wide (landscape).
  • Header and footer are the label on top and the caption below, repeated on every page.

Page setup · margins

Set 1-inch margins on every side

Word: Layout tab

Microsoft Word for Mac, sample letter. Mac shows centimetres here; 2.54 cm = 1 inch.

  1. Layout › Margins › Normal: 1" on all four sides.
  2. Or Margins › Custom Margins… and type 1" in Top, Bottom, Left and Right. Word converts it: 2.54 cm.

Docs: File › Page setup, type 1 in each margin box (inches).
Writer: Format › Page Style › Page, margins 1" (2.54 cm).

On Windows the Custom Margins box is called Page Setup; on the Mac it is Document.

Page setup · size and orientation

Match the paper in the document to the paper in the tray

Microsoft Word for Mac: Layout › Size / Orientation, or File › Page Setup… (shown). The paper list comes from the printer. Printer name masked.

  • A4 210 × 297 mm · Letter 8.5 × 11 in "short" · Long 8.5 × 13 in "long bond".
  • Size: Layout › Size. Pick Folio if your list shows it at 8.5 × 13 in. If not, More Paper Sizes (Mac: Page Setup › Paper Size › Manage Custom Sizes) and type 8.5 × 13 in.
  • Long = Folio, not Legal. Legal is 8.5 × 14 in. F4 (210 × 330 mm) is a little narrower, so check the numbers.
  • Portrait for letters and memos. Landscape for wide tables, like an inventory list.
  • Follow your office's practice for official letters, and change the printer's paper setting too.

Headers, footers and page numbers

Never type numbers by hand

Microsoft Word for Mac, sample letter: footer of page 1, header of page 2.

  1. Insert › Header or Footer, or double-click the top or bottom of the page. Word opens the Header & Footer tab.
  2. Page Number (or Insert › Page Number) › Bottom of Page. "Page X of Y" updates itself: here Page 1 of 2.
  3. Tick Different First Page when page 1 has a letterhead and no number.
  4. Double-click the body or click Close Header and Footer.

Docs: Insert › Headers & footers; Insert › Page numbers. Writer: Insert › Header and Footer; Insert › Page Number.

Never type page numbers by hand. They break the moment you add a paragraph.

Control where pages start

Page breaks and section breaks

Page break

Starts a new page right here. Ctrl + Enter in Word, Google Docs and LibreOffice.

Use it for: an annex or attendance sheet that must start on a fresh page.

§

Section break

Word: Layout › Breaks › Next Page. Each section can have its own orientation, margins or numbering.

Use it for: one landscape page with a wide table inside a portrait report.

Don't press Enter 15 times

Blank lines push text down today, but everything shifts the moment you edit a paragraph above.

Tip: turn on Show/Hide ¶ (Ctrl + Shift + 8) to see breaks.

Two more Layout buttons

Columns: sometimes. Line numbers: off.

Columns

Layout › Columns › Two for a newsletter, bulletin board notice or flyer. Letters and memos stay in one column.

Google Docs: Format › Columns · LibreOffice: Format › Columns

Line numbers

Small numbers in the left margin? Turn them off: Layout › Line Numbers › None.

LibreOffice: Tools › Line Numbering

Rule of thumb: official letters use one column, no line numbers, 1-inch margins.

Microsoft Word for Mac: Format › Columns (Layout › Columns › More Columns). Preview shows two columns.

Print settings

Print only what you need, the way you need it

  • Pages: type 1-3, 5 for pages 1, 2, 3 and 5.
  • Collated gives complete sets (1-2-3, 1-2-3). Uncollated gives 1-1-1, 2-2-2.
  • Both sides: automatic if the printer supports it, or "manually" (you flip the stack).
  • Scale to Paper Size fits an A4 file onto long bond, or the reverse.
  • Print to PDF makes a file instead of paper.

Paperless option

Save as PDF when it doesn't need ink

Looks the same on every screen

Word

File › Save As › PDF, or File › Export › Create PDF/XPS.

Google Docs

File › Download › PDF Document (.pdf).

LibreOffice

File › Export as PDF, or the PDF button on the toolbar.

Any app on Windows

Choose Microsoft Print to PDF as the printer in the print window.

Why PDF? Fonts, margins and page breaks stay exactly as you set them, and nobody can accidentally edit the letter. Keep the .docx as your editable master copy.

Save paper, ink and money

Small habits, big savings

At the office
  • Preview first, then print one test copy before the batch.
  • Print internal drafts double-sided and in grayscale.
  • Email the PDF instead of printing copies just to read.
  • Scrap paper only if it has no personal or taxpayer data; shred the rest.
At home
  • Kids' school modules: print only the pages needed with a page range.
  • Use grayscale for worksheets; save colour ink for photos.
  • Print two pages per sheet for reviewers and reading notes.
  • Keep receipts and bills as PDF in a folder instead of printing.

Checklist · official letter for signature

Ten checks before it goes to the chief's table

  • Correct paper size in file and tray
  • 1-inch margins, portrait
  • Letterhead or header in place
  • Date and reference are correct
  • Names and positions spelled right
  • No placeholders like [Insert Name]
  • Justified text, standard font sizes
  • Signature block stays with its paragraph
  • Page X of Y if 2 or more pages
  • Right number of copies, incl. receiving and file copy
