The big idea

Your computer is a filing cabinet.

In the records roomOn the computer
The cabinetA drive: C: (this PC), a flash drive, a shared drive, the cloud
A drawer or folderA folder , which can hold more folders
One paper or formA file : a letter, a spreadsheet, a scanned PDF
The label on the folderThe file name, so anyone can find it

Everyone in this group knows a records room. A drive is the cabinet, folders are the drawers and envelopes, and files are the actual papers.

Point out the key difference: a folder holds files; a file holds the content. You open a file to read or edit it. Ask: "Would you throw all your papers loose into the cabinet with no folders?" No, yet that's exactly what a crowded desktop is. Also mention the shared drive many offices use: it's just a cabinet everyone in the section can open.

Folder vs file

A folder holds files and other folders; it has no extension. A file holds the actual content.

Careful: a file ending in .exe is a program. Never open one that arrived by email or chat.
See extensions: in File Explorer, View › Show › File name extensions (Windows 11) or tick File name extensions on the View tab (Windows 10).

The extension is the short part after the last dot. It tells Windows which app opens the file. Turn on "File name extensions" live so they can see them.

Point out that the same .docx opens in Word, Google Docs or LibreOffice. LibreOffice also has its own formats (.odt, .ods) but saves .docx fine. Stress the warning: an attachment called "Notice.pdf.exe" is a program pretending to be a PDF. That's a classic trick we'll see again in 1.4.

Everyday actions

Create, rename, move, copy, delete

Right-click works for all of these
Ctrl + Shift + NNew folder (in File Explorer) F2Rename the selected file or folder Ctrl + CCopy: the original stays Ctrl + XCut: to move it somewhere else Ctrl + VPaste into the folder you're in Ctrl + ZUndo the last action. Your best friend. DeleteSend to the Recycle Bin

The Recycle Bin is a safety net

Deleted by mistake? Open the Recycle Bin, right-click the file, choose Restore. It goes back where it was.

No safety net: files deleted with Shift + Delete, or from most flash drives and shared drives, skip the Recycle Bin.

On a Mac, use Cmd instead of Ctrl; the bin is called Trash.

Demo each one live in a practice folder: new folder, F2 rename, copy-paste, cut-paste, delete, then restore from the Recycle Bin. Go slowly; this is the most useful slide of the topic for beginners.

Explain copy versus cut: copy makes a twin; cut moves the original. And Ctrl+Z undoes most mistakes, including an accidental move. Stress the warning: on the shared drive, a delete may be permanent for everyone, so think twice.

A naming habit

Date first, then type, then subject

2026-10-26 Memo - Supplies Request.docx

YEAR-MONTH-DAY · Type · Subject

Why it works

  • YYYY-MM-DD sorts by itself in date order, oldest to newest.
  • The type (Memo, Letter, Report, Receipt) lets you scan a long list.
  • The subject tells anyone what's inside without opening it.

Names we've all seen

  • final na jud (2) FINAL.docx
  • Document1.docx
  • New folder (7)
  • memo 10/26.docx won't even save. Windows doesn't allow any of these in a name: \ / : * ? " < > |

This is the habit I want you to take home. Year-month-day first, because then the computer sorts your files by date automatically. Then the type, then a short subject.

Ask: "Who has a file named 'final' that isn't final?" Everyone laughs. If you need versions, add _v1, _v2 at the end instead. Point out that slashes and colons are not allowed in Windows file names, which is another reason to write dates as 2026-10-26.

No. That's the app's default name; you'll have ten of them by Friday.
