Save as type

Edit in .docx, send in .pdf

✏️

To edit

  • .docx: Word's standard, opens in Docs and Writer too
  • .odt: LibreOffice's standard
  • .doc: old format, re-save as .docx
📤

To send

  • .pdf: a fixed copy
  • Looks the same on any phone or PC
  • Not easily edited
Rule of thumb: edit in .docx, send in .pdf, keep both.

Welcome to Module 2, where we build one real letter,
layer by layer. In this video, you'll learn your way around the word
processor, the commands for saving, the right file format,
and how never to lose a document again.
On a typewriter, one typo near the end meant retyping
the whole page. A word processor is a typewriter that lets you change
your mind. Fix one letter or move a paragraph,
and the page adjusts by itself.
Change the font any time.
And save it once, so next year's memo needs only
a new date.
Three common word processors.
Microsoft Word is on most office PCs.
Google Docs runs in the browser and saves to Google Drive by itself.
LibreOffice Writer is free, works offline,
and saves doc x too. To open Word, press the Windows key,
type Word, and choose Blank document.
Here's the Word window.
The title bar shows the file's name, and the Quick Access Toolbar keeps Save,
Undo and Redo in reach. The ribbon groups commands into tabs.
The File tab holds New, Open,
Save As, Print and Export.
The page is the document area.
The status bar shows the page and word count.
And zoom only changes the view, not the printout.
Four commands do most of the work. New starts a blank document: Control N.
Open brings back a saved file: Control O.
Save updates the same file, same name, same place:
Control S. Save As makes a new copy with a new name,
folder or format: F12 in Word.
Think photocopier:
Save writes on the original, and Save As labels a
copy.
The most common mistake: you open October's report, update it,
and press Control S. October's version is gone.
Open October's file, press F12 for Save As,
and name the copy with November.
Now edit: the period becomes November.
October's file stays safe.
In Google Docs, use File, Make a copy.
Which format?
To edit, use doc x, Word's standard,
which Google Docs and LibreOffice open too. LibreOffice's own is o d t.
For final copies, use PDF:
a fixed copy that looks the same on any phone
or PC. Rule of thumb:
edit in doc x, send in PDF, and keep both.
Where does the file live?
Local means this PC, a shared drive or a flash drive.
It works offline, but if it dies,
so does the file.
Cloud means OneDrive, SharePoint or Google Drive:
it saves as you type and keeps version history.
Taxpayer files go only where your office allows,
never a personal Google Drive.
At home, the cloud is perfect for the kids' school
files.
Now our running example.
Press Control N, then paste the raw text of the workshop invitation.
Press F12 and name it by type, subject and date:
Letter, Digital Skills Workshop Invitation, then the date.
Then export a PDF copy:
File, Save As, PDF.
At home, same pattern: Budget, Household, then the month.
Then the power goes out. Is your letter gone?
Don't panic.
Reopen Word:
the Document Recovery pane lists rescued files.
Google Docs already saved it, and version history restores older
states. Reopen Writer and click Start.
But recovery copies come only about every ten minutes,
so press Control S after every paragraph.
Quick check.
You want to update October's report for November,
but keep October's file unchanged.
What do you do first? Edit, then Control S?
Save As with a new name? Export a PDF and edit that?
Or zoom to 150 percent?
Think about it for a moment. The answer: it's B.
Save As first, then edit.
To recap. Navigate:
title bar, ribbon, ruler, page, status bar and zoom.
Handle files:
Save updates the file, Save As makes a copy.
Protect:
good names, and Control S often.
