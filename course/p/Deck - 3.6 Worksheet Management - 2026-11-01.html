The big idea

A workbook is a binder. Each worksheet is a tabbed divider.

  • Workbook = the whole file, like one binder on the shelf.
  • Worksheet = one page section inside, with its own tab at the bottom of the screen.
  • Coloured, clearly labelled tabs help anyone find January in a second.
  • The Summary divider in front gives the boss the totals first.

Where the tabs live

Right-click a sheet tab to manage it

Bottom-left of the window

Microsoft Excel for Mac, sample Office Supplies Inventory. Mac: Control-click a tab for the same menu.

  1. Jan, Feb, Mar, Summary: one tab per sheet. The active tab is the light one.
  2. + adds a new sheet (Shift + F11).
  3. Right-click a tab for its menu: Insert, Delete, Rename, Move or Copy, Tab Color, Protect Sheet, Hide, Unhide. Double-click a tab to rename it.

Google Sheets and LibreOffice Calc have the same ideas with slightly different names.

Choose the right action

Hide, delete or protect: they are not the same

Hide

Takes a sheet out of view, for example a helper sheet of price lists. Anyone can unhide it in two clicks.

Delete

Removes the sheet and everything on it. Formulas that pointed to it show #REF!.

Protect

Lets people see the sheet but stops them from changing locked cells, like your formulas.

Hiding is not security. Never "hide" client details or other confidential data in a shared file. If people shouldn't see it, it shouldn't be in that file.

Referencing other sheets

Sheet name, then !, then the cell.

Microsoft Excel for Mac, sample Office Supplies Inventory. Feb and Mar use the sample quantities. Show formulas: Ctrl+`.

  • =Jan!E10 means "cell E10 on the Jan sheet": B2 shows ₱22,039.00. Easiest way: type =, click the Jan tab, click E10, press Enter.
  • Same for Feb and Mar: B3 =Feb!E10, B4 =Mar!E10.
  • B5 =SUM(B2:B4) = ₱64,209.00 for the quarter; B6 =AVERAGE(B2:B4) = ₱21,403.00.
  • Names with spaces need quotes: ='Jan 2026'!E10. LibreOffice writes =$Jan.E10. Clicking writes it for you.

Find it in seconds

Find and Replace

Microsoft Excel for Mac, sample Jan sheet (sorted). Mac labels the box Find entire cells only; Windows says Match entire cell contents.

Ctrl + FFind a word or number anywhere on the sheet, like "Envelope". Mac Excel: Cmd + F. Ctrl + HReplace one spelling with another, for example "Ballpen" with "Ball pen". Same key on a Mac.
  1. Type what to find and what to put instead.
  2. Find All first: "long" is in 3 cells (bond paper, folder, envelope), not one.
  3. Tick Match entire cell contents, or replace one at a time, before you press Replace All.

Sort · Data > Sort

Largest Total Cost first

Microsoft Excel for Mac, sample Office Supplies Inventory.

  1. Click one cell inside the table (not the whole column), then Data > Sort. Sheets: Data > Sort range > Advanced, tick "Data has header row".
  2. Sort by Total Cost, Largest to Smallest. Keep My list has headers ticked.
  3. Long bond paper comes first at ₱7,950.00. The TOTAL row stays out of the sort.
Never sort one column alone. The rows get mixed up: ink could end up with the price of paper. Keep a blank row above TOTAL, or select A1:E9 only.

Filter · show only what you need

Show only items over ₱300 each

Microsoft Excel for Mac, sample Office Supplies Inventory.

  • Excel: Data > Filter (Ctrl + Shift + L; Mac Cmd + Shift + F). Sheets: Data > Create a filter. Calc: Data > AutoFilter.
  • Arrow on Unit Cost > Number Filters > Greater Than > 300. 3 of 9 items stay; blue row numbers say a filter is on. The TOTAL row right under the list hides too: keep a blank row above it.
  • Select the visible totals: the status bar says ₱6,110.00.
  • Watch out: =SUM still adds hidden rows. E10 stays ₱22,039.00, and so does the Summary. Clear the filter when done.

Sheet protection · basics

Let others type inputs, but not break your formulas

  1. Unlock the input cells (for example Qty, C2:C9): Format Cells > Protection > untick Locked. Every cell is locked by default.
  2. Turn on protection. Excel: Review > Protect Sheet. Sheets: Data > Protect sheets and ranges. Calc: Tools > Protect Sheet.
  3. Add a password only if your section can keep it safe, and record who has it.
Result: co-workers can update quantities, but the Total Cost formulas and the SUM stay safe from accidental typing.
Protection is not encryption. It prevents accidental edits. To keep a file private, store it in the right shared folder with the right access, or use a file password approved by your ICT focal person.

Preparing to print

One page wide, headers on every page

  1. Preview first: Ctrl + P. Count the pages.
  2. Fit to one page wide. Excel: Scaling > Fit All Columns on One Page. Sheets: Scale > Fit to width. Calc: Format > Page Style > Sheet > Scale.
  3. Print titles (repeat row 1). Excel: Page Layout > Print Titles > Rows to repeat at top $1:$1. Calc: Format > Print Ranges > Edit. Sheets: freeze row 1, then repeat frozen rows in the print settings.
  4. Landscape for wide tables; add the sheet name and page number in the footer.
