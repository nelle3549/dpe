The big idea

Mail merge works like party loot bags.

  • One design for every bag: that's your letter.
  • One list of the kids who are coming: that's your data source.
  • A blank name tag on each bag: that's the merge field. Each bag gets a different name.
Result: one letter + one list = many personalised letters, in one file.

How it works

Three parts make one merge

1 · Main document

The letter that stays the same for everyone: the workshop date, venue, body, signature.

+

2 · Data source

A separate list, usually a spreadsheet. One row per person, one column per detail.

+

3 · Merge fields

Placeholders in the letter, like «Name», linked to the list's column headers.

=

Merged letters

One new file with a finished letter for each row: Juan's, Ana's, Pedro's…

Key idea: the data stays in the list. Fix a name in the list once, merge again, and every letter is corrected.

Step 0 · The data source

Build the list in a spreadsheet first

Excel · Google Sheets · LibreOffice Calc

Microsoft Excel for Mac. Sample names and addresses only. On Windows, close with the X at the top right.

  • One header row in row 1. These become your field names.
  • One person per row, no blank rows in between.
  • One detail per column: no merged cells, no titles above the headers.
  • Save and close the file before you connect it. Note the sheet name at the bottom.

Microsoft Word for Mac, Mailings tab.

Step 1 · The main document

Write it once. Leave "name tags" where details change.

  • Everything in plain text is the same for everyone.
  • Each «field» is filled in from the list, one row per letter.
  • A field can be used more than once, like «Section» here.

Microsoft Word · Mailings tab

Connect the letter to the list

Steps 1 to 3

Microsoft Word for Mac. Word for Windows has the same buttons on its Mailings tab.

  1. Open your letter, then Mailings › Start Mail Merge › Letters.
  2. Select Recipients › Use an Existing List… and open Workshop Invitees.xlsx.
  3. Pick the sheet with the list and click OK.Mac: Open Workbook, Cell Range Entire Worksheet. Windows: Select Table, keep "First row of data contains column headers" ticked.

Microsoft Word · Mailings tab

Insert fields, preview, finish

Steps 4 to 6

Microsoft Word for Mac, Mailings tab.

  1. Select the name you typed (or click where a detail goes), then Insert Merge Field › Name. Repeat for Position and Section. Type the spaces and punctuation yourself.
  2. Click Preview Results and use the arrows to see each person's letter. Click it again to see the fields.
  3. Finish & Merge › Edit Individual Documents… Word opens a new file (e.g. Letters1) with one letter per person. Save it.Windows asks which records: choose All, then OK.
Save both files: the main document (with fields) and the merged file (with names). The merged file is the one you submit for Lab 2.

What you get

One file, one letter per row

New Word file · 4 pages
Each letter starts on a new page (Word adds a section break between them), so you can print the whole file at once.

Hands-on · in your own apps

Merge your invitation to 3 people

Try it nowSubmit in the portal when your merged file opens
  1. In a spreadsheet, type Name, Position, Section, Email in row 1, then 3 sample people in rows 2 to 4. Save as Workshop Invitees and close it.
  2. Open your invitation letter from Topic 2.3.
  3. Mailings › Start Mail Merge › Letters, then Select Recipients › Use an Existing List, choose Workshop Invitees, then OK.
  1. Change Dear Colleagues, to Dear + Insert Merge Field › Name + :. Add Name, Position and Section lines above it the same way.
  2. Preview Results and click through all 3.
  3. Finish & Merge › Edit Individual Documents › All. Save the new file as Merged Invitations.
Greyed-out buttons: you skipped Start Mail Merge or Select Recipients.
Field list shows F1, F2: headers are not in row 1. Fix the sheet, reconnect.

Google Docs · Google Sheets

Letters: Docs + Sheets + an add-on

Way 1 of 2

Google Docs and Sheets in a free Google account. Marketplace results are examples, not a recommendation.

  1. Make the list in Google Sheets: Name, Position, Section, Email in row 1, on the first tab.
  2. In your Google Docs letter, type each field where it goes, spelled like the header: <<Name>>, <<Position>>.Some add-ons use {{Name}} instead. Use the marker yours asks for.
  3. Extensions › Add-ons › Get add-ons, search "mail merge", and install the one your ICT focal person approved.
  4. Open it from Extensions, pick your sheet, and preview one row.
  5. Merge to a new Google Doc, then File › Download as Word (.docx) or PDF.
Ask your ICT focal person first. An add-on can read the sheet you connect, so never connect a sheet with personal or client data to an add-on.

Gmail · Google Sheets

Emails: Gmail's own mail merge

Way 2 of 2

On some paid Workspace plans

  1. Compose, then click Use mail merge beside the "To" line and turn it on.
  2. Add from a spreadsheet, pick your sheet, Insert, choose the Email and name columns, Finish.
  3. In the message, type @ and pick a column, e.g. @Position.
  4. Send one to yourself first, then send to all.

Before you print or send

Preview, then check like a proofreader

  1. Look at the first, last and one middle letter, not just the first.
  2. Check spaces and punctuation around every field: "Dear Ana Reyes:" not "DearAna Reyes :".
  3. Check the record count: 3 people in the list should mean 3 letters.
  4. Use Edit Recipient List to untick anyone who should not get a letter.
  5. Print one test page before printing the whole batch.

Troubleshooting

Four common mail merge errors

What you seeLikely causeFix
Wrong names, or no names at allYou picked the wrong sheet or table in Select Table.Select Recipients again and choose the sheet that holds the list.
Blank letters at the endEmpty rows, or rows with only a space, in the list.Delete empty rows in the sheet, or untick them in Edit Recipient List.
Numbers lose their formatWord takes the raw value: 1500 instead of ₱1,500.00.Type the amount as text in the sheet, or fix the format in Word before merging.
Dates look differentA date like 19 November 2026 may show as 11/19/2026.Type the date as text in the sheet, or keep the date in the main letter instead.
