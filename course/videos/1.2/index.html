Ever spent ten minutes looking for a letter you know
you saved?
With a taxpayer waiting, it feels longer.
In this video, we'll tour the desktop and File Explorer,
practise the everyday file actions, agree on one naming habit,
and learn to find any file in seconds.
Your computer works like a records room. A drive is the cabinet:
this PC, a flash drive, the shared drive or the
cloud. A folder is a drawer, and it can hold more folders.
A file is one paper: a letter, a spreadsheet, a scan.
And the file name is the label, so anyone can find it.
First stop:
the desktop.
The icons are shortcuts, files and the Recycle Bin.
Each open app lives in a window you can minimize, maximize or close.
The Start button opens your apps, settings and power off.
The taskbar shows pinned apps and open windows.
Windows D shows the desktop. Treat it as a work table,
not a storage room.
Second stop: File Explorer.
Press Windows E to open it. The left pane lists Desktop, Downloads,
Documents and your drives, including any flash drive.
The address bar shows the path.
Read it like an address: cabinet, drawer, folder.
And the file list shows what's inside.
Click a column header to sort it.
The short part after the last dot is the extension.
It tells Windows which app opens the file:
doc x for documents, x l s x for spreadsheets,
PDF for fixed pages like forms,
j p g for pictures. But watch out for e x e: a program.
Notice dot PDF dot e x e is pretending to
be a PDF, so never open one from email or chat. To see extensions:
View, Show, File name extensions.
Now the everyday actions.
Right-click works, but shortcuts are faster.
Control Shift N makes a new folder. F2 renames the selected file.
Control C copies, Control X cuts,
Control V pastes.
Delete sends it to the Recycle Bin, where you can choose Restore.
And Control Z undoes your last action.
But there's no safety net with Shift Delete,
or on most flash drives and shared drives.
Here's the habit to take home: date first, then type, then subject.
For example: twenty twenty-six, ten, twenty-six, Memo, Supplies Request.
It sorts itself by date, and anyone can tell what's inside.
Compare the names we've all seen: final na jud, FINAL.
Document1. New folder seven.
Or slashes, which Windows won't accept.
Need versions? Add v1, v2 at the end.
At the office, keep a simple structure: your section folder, one folder per year,
then numbered folders by type. Zero one Memos and Letters, zero two Reports,
zero three Inventory.
The numbers fix the order.
At home: a Family folder, with Kids School,
and Receipts 2026 for the CEPALCO and water bills.
And at work, agree on one structure as a section.
Still can't find it?
Press the Windows key and type part of the name.
Or use the search box in File Explorer: it looks inside every sub-folder too.
Sort by date modified to see your recent work.
And Home in File Explorer lists your recent files.
Good names make search work:
type Supplies, and the memo appears.
Quick check.
Which file name will be easiest to find and sort next year?
Final na talaga, memo supplies with slashes in the date,
the one that starts with the date, or Document1?
Think about it for a moment. The answer: it's C.
Date first sorts itself, and the type and subject say what's inside.
To recap. Navigate:
the desktop is a work table, and Windows E opens File Explorer.
Organize:
folders by year and type, and names that start with
the date. Recover:
Control Z, the Recycle Bin and search undo most mistakes.
