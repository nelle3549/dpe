Step 1 · Insert

Insert a table in three clicks

Plan your columns first

Microsoft Word for Mac, sample letter. On Windows: Insert › Table › Insert Table.

  1. Click the empty line under Here is the schedule:, then Insert › Table.
  2. Drag across the grid, or choose Insert Table… and type 3 columns, 6 rows.
  3. Click OK.
  4. The empty grid appears, cursor in the first cell. Word adds the Table Design and Table Layout tabs.

Docs: Insert › Table, pick the size on the grid. Writer: Table › Insert Table (Ctrl+F12).

Count before you click: 3 columns (Time, Activity, Venue) and 6 rows: 1 header + 5 time slots. Rows are easy to add later.

Step 3 · Change the structure

Add, delete and merge

Right-click works in all three apps

Microsoft Word for Mac, sample letter. Windows has the same Table Layout tab (older versions: Layout).

  1. We forgot lunch: click in the Word processing row, then Table Layout › Insert Below (or right-click › Insert › Rows Below).
  2. A new empty row appears under it.
  3. Type the lunch break with Tab.
  4. Title row: Insert Above, select the new row's cells, then Merge Cells.
  5. One cell across the whole table. Use merges sparingly.
Delete a row: Table Layout › Delete › Delete Rows (or right-click › Delete). The Delete key only empties the cells; the grid stays.

Docs: right-click › Insert row below, Merge cells. Writer: Table › Insert, Table › Merge Cells.

Step 4 · Size and line up

Column width and alignment

↔ Column width

  • Drag the line between two columns.
  • Double-click that line: the column fits its longest entry (Word, Writer).
  • AutoFit (Word: Layout › AutoFit): fit the contents, or fill the page width.
  • Distribute Columns makes them all equal (Docs: right-click › Distribute columns).

Alignment

  • Text in a cell: select cells, then use the alignment buttons, like any paragraph. Word's Layout tab adds top, middle and bottom.
  • Header row: bold and centered usually reads best.
  • Numbers and amounts: right-align so the digits line up.
  • The whole table: select it and center it on the page (Word: Table Properties › Center).
Long schedule or list? In Word, mark the header row as Repeat Header Rows (Layout tab) so it shows again on every page.

Step 5 · Make it readable

Borders, shading and table styles

Word: Table Design tab

Microsoft Word for Mac, sample letter. The Table Design tab is the same on Windows.

  1. Plain grid first: header row bold and centered, columns fitted (double-click a column border, or Table Layout › AutoFit).
  2. Click in the table, open Table Design, pick a light style. Tick Header Row and Banded Rows; untick First Column.
  3. Shaded header, banded rows: easy to follow across. Keep it light for printing.

Docs: right-click › Table properties: border colour and width, cell background colour.

Writer: Table › AutoFormat Styles, or Table Properties › Borders and Background.

Graphics · pictures

Insert a picture, then resize from a corner

Microsoft Word for Mac, sample stock photo. Windows: Insert › Pictures › This Device.

  1. Insert › Pictures (Mac: Picture from File; Windows: This Device). Click the photo: eight handles appear.
  2. Side handle: only one direction changes. Faces stretch. Undo!
  3. Corner handle: same shape, just smaller.
  4. Exact size: Picture Format › Height and Width. On Windows, Lock aspect ratio is under the small arrow in the Size group; on a Mac, click the lock.

Docs: Insert › Image › Upload from computer. Writer: Insert › Image.

Never drag a side handle on a photo of people or a logo. Drag a corner, or hold Shift while dragging.

Graphics · wrapping

How text flows around a picture

Word: Layout Options button

Microsoft Word for Mac, practice invitation. Sample photo.

  • In Line with Text: the picture sits in the line like a big letter. The default; safest for letters.
  • Square: text wraps around the sides. Good for invitations and newsletters.
  • Change it with the Layout Options button beside the picture, or Picture Format › Wrap Text (on a narrow Mac window it sits under Arrange).

Top and Bottom: text above and below only. Behind / In Front: floats over or under the text, for watermarks only.

Same idea, other names: Docs: In line · Wrap text · Break text · Behind text · In front of text. Writer: right-click › Wrap › None · Parallel · Optimal · Before · After · Through.

Graphics · drawn elements

Shapes, icons and diagrams

Shapes

Arrows, boxes, callouts, lines. Word: Insert › Shapes.

Icons

Simple symbols you can recolour. Word (Microsoft 365): Insert › Icons.

SmartArt

Ready-made lists, processes, org charts. Word: Insert › SmartArt.

No SmartArt? Google Docs: Insert › Drawing › New to draw boxes and arrows. Writer: Insert › Shape. A 2-column table also works for a simple process.

Putting it together

A simple letterhead with a logo

Sample logo

Microsoft Word for Mac, sample logo and office. Windows has the same Header & Footer tab.

  1. Open the header: double-click the top margin (or Insert › Header). Insert a 2-column table, set Borders › No Border.
  2. Left cell: the logo, resized from a corner. Right cell: office name, section, contact.
  3. Add a bottom border line, then Close Header and Footer.
  4. The header shows dimmed while you type the letter, and repeats on every page.

Docs: Insert › Headers & footers › Header. Writer: Insert › Header and Footer › Header.

Add a letterhead with a logo or graphic

Five stepsSubmit in the portal when done
  1. Double-click the top margin to open the header (Docs: Insert › Headers & footers › Header).
  2. Insert a picture: a sample logo from the training folder, or Insert › Icons in Word.
